🐾 GuaipeCare — Stack Tecnológica

Arquitetura de baixo custo e alta eficiência para identificação de animais comunitários

UFPEL — Metodologia Científica
Profs. Ana Marilza Pernas e Tatiana Aires
Hardware Físico

Tag NFC Passiva

Chips NTAG213 / NTAG215 acoplados à coleira. Redirecionamento instantâneo via aproximação.

Por que foi escolhido: Custo baixíssimo (~R$ 1,50), sem bateria, impermeável e dispensa instalação de aplicativos.
Backend / API

Python 3 & Flask

Microframework web para roteamento RESTful, Application Factory e tratamento seguro de requisições.

Por que foi escolhido: Rápido ciclo de desenvolvimento no MVP, footprint de memória mínimo e facilidade de manutenção.
Banco de Dados

SQLite & SQLAlchemy

Banco de dados relacional embutido com ORM para garantia de integridade referencial e histórico desacoplado.

Por que foi escolhido: Não requer servidor de banco dedicado, portátil em arquivo único e seguro para replicação da demo.
Frontend & GPS

Vanilla JS & Geolocation

HTML5, Jinja2 e JavaScript nativo com navigator.geolocation e envio assíncrono via fetch.

Por que foi escolhido: Zero bibliotecas externas pesadas, carregamento ultrarrápido em 4G/3G e consentimento voluntário.
